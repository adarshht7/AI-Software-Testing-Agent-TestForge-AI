# TestForge AI — AI Software Testing Agent

## About the Project
TestForge AI is an AI-powered software testing agent that automatically generates test cases, tests websites, analyzes failures, and creates testing reports.

## Features
- AI-based test case generation
- Automated website testing
- Test failure analysis using AI
- HTML testing report
- CSV results export

## Technologies Used
- Python
- OpenRouter API
- Playwright
- Pandas
- Google Colab

## How It Works
1. Enter the website URL.
2. Describe the testing requirements.
3. AI generates test cases.
4. Playwright executes the tests.
5. AI analyzes failures and generates a report.

## How to Run
1. Open the project notebook in Google Colab.
2. Install the required libraries.
3. Enter your OpenRouter API key.
4. Provide the website URL and testing requirements.
5. Run the code to generate test results.
